# 無人機大亂鬥

以雲林科技大學校園為戰場的 3D 即時戰略小遊戲。玩家指揮旋翼機、固定翼機、VTOL、無人車組成的異質部隊，和電腦對手進行 3v3 或 5v5 對抗。

## 如何執行

1. 確認 `index.html`、`style.css`、`main.js` 三個檔案放在同一個資料夾。
2. 用瀏覽器（Chrome、Edge、Safari、Firefox 皆可）打開 `index.html`。
3. 不需要安裝、不需要伺服器，也不需要連網。

電腦與手機都能玩，手機建議橫向操作。若畫面不順，可在暫停選單把「畫質」切到「低」。

## 檔案結構

| 檔案 | 內容 |
| --- | --- |
| `index.html` | 頁面結構：開始畫面、對戰設定、選陣容、操作說明、暫停、結算、戰鬥介面 |
| `style.css` | 全部樣式（貼紙風介面、按鈕、單位卡、小地圖、手機版面） |
| `main.js` | 開頭是 Three.js r128 3D 引擎，後面是遊戲程式（設定、尋路、場景、模型、特效、遊戲核心、AI、輸入、介面、主迴圈） |
| `規格書.docx` / `規格書.pdf` | 完整規格書，附程式碼 |

本專案沒有 assets 資料夾：3D 模型、地圖貼圖、圖示都由程式即時繪製，音效用 Web Audio API 即時合成，因此不需要任何外部素材。

## 遊戲流程

開始遊戲 → 對戰設定（規模、模式、難度、戰爭迷霧）→ 選陣容 → 戰鬥 → 結算

| 模式 | 勝利條件 |
| --- | --- |
| 佔點模式 | 佔領 A 荷花池、B 設計學院、C 運動場；每個佔點每秒 +1 分、擊毀敵人 +3 分，先到 150 分獲勝，陣亡 8 秒後重生 |
| 殲滅模式 | 消滅所有敵人，不重生 |

兩種模式時限都是 5 分鐘，時間到時佔點模式比分數，殲滅模式比剩餘總血量。

## 載具

| 載具 | 特性 | 一般攻擊 | 特殊技能 |
| --- | --- | --- | --- |
| 旋翼 | 能懸停、轉向靈活 | 連發機槍 | 懸停鎖定：原地停 4 秒，射速加倍 |
| 固定翼 | 最快、視野最大，不能停，只能繞圈 | 追蹤導彈 | 轟炸航線：在地圖拖一條線，沿線投下 6 顆炸彈 |
| VTOL | 可切換旋翼／固定翼模式 | 機槍或導彈（依模式） | 模式切換：1.5 秒，切換中較脆弱 |
| 無人車 | 最耐打，會被建築與水池擋住 | 拋物線砲擊 | 防空飛彈：連射 3 枚打空中目標 |

空中載具都有熱焰彈，可讓追蹤中的導彈轉向。克制關係：無人車克旋翼、旋翼克固定翼、固定翼克無人車。

## 操作方式

| 動作 | 電腦 | 手機 |
| --- | --- | --- |
| 選取 | 左鍵點選、左鍵拖曳框選、Shift 加選、雙擊選同類型 | 點單位或單位卡、長按後拖曳框選 |
| 移動／攻擊 | 右鍵點地面／右鍵點敵人 | 選取後點地面／點敵人 |
| 攻擊移動 | A 後左鍵點地面 | 「攻擊移動」按鈕後點地面 |
| 技能／熱焰彈／停止 | Q／F／S | 右下角按鈕 |
| 編隊 | Ctrl + 1–5 儲存，1–5 叫出 | 長按「編隊」儲存，短按叫出 |
| 鏡頭 | 方向鍵或滑鼠移到邊緣；滾輪縮放；中鍵或 Z、C 旋轉；空白鍵回到選取單位 | 單指或雙指拖曳、雙指捏合縮放、雙指旋轉 |
| 其他 | Esc 暫停、M 靜音、點小地圖跳轉 | 右上角暫停與靜音 |

## 技術說明

- 3D 繪圖：Three.js r128（WebGL），卡通色階材質加描邊
- 戰爭迷霧：以著色器依視野貼圖調暗未探索區域
- 無人車尋路：20 單位格網上的 A* 演算法，道路成本較低
- 敵方 AI：規則型指揮官，依難度調整決策頻率、撤退、集火與技能時機
- 設定（音量、畫質、上次的對戰設定）存在瀏覽器的 localStorage
