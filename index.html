操作說明

選取單位左鍵點選；左鍵拖曳框選；Shift + 左鍵加選；雙擊選同類型
移動 / 攻擊右鍵點地面移動；右鍵點敵人集火
攻擊移動A 後左鍵點地面，沿路遇敵就打
停止S
特殊技能Q；固定翼按 Q 後在地圖拖曳轟炸航線
熱焰彈F，被導彈鎖定時使用
編隊Ctrl + 1–5 儲存，1–5 叫出，連按兩下跳過去
鏡頭方向鍵或滑鼠移到邊緣捲動；滾輪縮放；中鍵拖曳或 Z / C 旋轉；空白鍵 回到選取單位
其他Esc 暫停；M 靜音；點小地圖跳轉
選取單位點單位或下方單位卡；長按 0.4 秒後拖曳框選；雙擊選同類型；開「加選」後點單位可多選
移動 / 攻擊選取後點地面移動；點敵人集火
攻擊移動按「攻擊移動」後點地面
技能 / 熱焰彈按右下按鈕；固定翼按「技能」後用手指拖出轟炸航線
編隊長按「編隊」儲存目前選取，短按叫出
鏡頭單指或雙指拖曳移動；雙指捏合縮放；雙指旋轉轉視角

玩法重點

克制關係無人車克旋翼、旋翼克固定翼、固定翼克無人車
佔點站進圓圈推進佔領度；無人車算 2 台；高速飛行的固定翼不能佔點
地形無人車不能穿過建築與水池，走道路最快；飛機可以直接飛越
